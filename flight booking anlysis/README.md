#  Flight Booking Analytics

A complete data analytics project focused on analyzing flight booking data and extracting meaningful business insights.

##  Tools & Technologies

- Python
- SQL
- Excel
- Power BI
- Data Analysis
- Data Visualization

##  Project Structure

- `data` — Raw datasets
- `cleaned_data` — Cleaned datasets
- `analysis` — Data analysis
- `sql` — SQL queries
- `excel` — Excel analysis
- `powerbi` — Power BI dashboard
- `dash` — Dashboard application
- `scripts` — Python scripts

##  Project Goals

- Clean and prepare flight booking data
- Perform exploratory data analysis
- Analyze booking trends
- Extract business insights
- Build dashboards and visualizations
